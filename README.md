# Matteo Fitness - aggiornamento GitHub Pages

## File inclusi
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- icon.svg
- icon-180.svg

## Pubblicazione
1. Apri il repository `matteo-fitness` su GitHub.
2. Carica questi file nella root del repository, sostituendo quelli esistenti.
3. Crea un commit, per esempio `Aggiornamento app fitness`.
4. Attendi 1-3 minuti e ricarica la pagina GitHub Pages.
5. Su iPhone, apri il sito in Safari e seleziona Condividi > Aggiungi alla schermata Home.

## Funzioni
- Scheda Giorno A e Giorno B completa
- Registrazione di kg, ripetizioni e serie completate
- Timer di recupero con +30 secondi
- Storico locale
- Progressi e carico massimo per esercizio
- Installazione come PWA e funzionamento offline

## Nota dati
I dati sono salvati nel localStorage del browser del dispositivo. La cancellazione dei dati del sito elimina lo storico. Per sincronizzazione cloud servirà in futuro un backend, per esempio Supabase o Firebase.
